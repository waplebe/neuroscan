# NeuroScan

**Live demo:** https://asterius.pro/neuroscan/

An interactive 3D brain atlas in the browser, built with Three.js/WebGL. Single HTML file, runs on desktop and mobile.

## Features

- Layered anatomy: surface, cortex, white matter, deep structures, brainstem
- Anatomical, functional and Brodmann-area maps
- Sagittal, axial and coronal slicing; wireframe mode
- Functional networks (default mode, sensorimotor, attention) and a 22-region connectivity matrix with animated arcs
- Simulated fMRI BOLD overlay; brain states (wake, sleep, meditation, stress) driving EEG bands δ/θ/α/β/γ
- Built-in neuroscience encyclopedia, RU/EN, dark/light themes

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
